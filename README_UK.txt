SPANIX Games — оновлений пакет інтеграції

Що оновлено в цій збірці:
- Основний бот збережений з наданого коду.
- Меню бота має 3 кнопки в кожному з перших трьох рядів, підтримка — в третьому ряду, гра — окремою широкою кнопкою в четвертому.
- У боті вже є налаштування кнопки гри в адмін-панелі: текст, стиль/колір і Telegram Premium Emoji ID.
- У міні-аппі бренд SPANIX Games, курс показу 100 Stars = 1 TON.
- Доступ до адмін-панелі міні-аппа включає ID 8759868224, знайдений у коді основного бота.
- Поповнення Stars/TON і демо-поповнення в самому міні-аппі вимкнені; гравця спрямовує до основного бота.
- Нові профілі міні-аппа починають з нульового балансу.

Перевірки:
- Python-компіляція обох файлів бота пройшла.
- JavaScript міні-аппа перевірено через Node.js --check.

ВАЖЛИВО — ЩО ЩЕ НЕ ГОТОВО ДЛЯ РЕАЛЬНИХ ГРОШЕЙ:
Ця збірка ще не має спільного серверного транзакційного балансу між ботом і грою. Ігровий рушій досі змінює баланс у localStorage браузера. Не завершені серверна перевірка TON-платежів, атомарне списання ставок/зарахування виграшів та повний цикл виведення Stars/TON з резервуванням суми, підтвердженням адміністратора, позначенням фактичної виплати і запитом відгуку. Вимкнення поповнення з міні-аппа не створює синхронізацію балансу само по собі. Не запускайте реальні платежі, доки ці функції не будуть реалізовані та протестовані.

Перед розгортанням встановіть реальний HTTPS MINI_APP_URL у налаштуваннях бота, username бота в CONFIG.botUsername, налаштування власника/репозиторію/гаманця/підтримки та секрети у змінних середовища. Не публікуйте BOT_TOKEN або GitHub token.
